3. 기능 스펙 (이식할 것들)

A. 검색 자동 채우기

- Google Books API (intitle: 검색, maxResults 5)
- 결과 클릭 → title/author/publisher/ISBN/표지 URL 자동 입력
- 자동 채움 후 결과 목록은 접힘 + 상태 문구 표시
  ("Filled in from Google Books. 필요하면 수정하세요.")
- 모달 열 때마다 검색창·결과·상태문구 초기화 (이전 검색 잔상 금지)
- Enter 키 = 검색 실행 (form submit 아님)

B. 표지 이미지 UX

- 표지 박스 = 드롭존 + 붙여넣기(Ctrl+V) + 클릭 시 파일 선택, 3-in-1
- 버튼 노출 없음. "Paste, drag or upload an image" 플레이스홀더만
- 업로드 시 520px JPEG 자동 압축 (원본 크기 무관)
- ↻ 90° 회전 버튼 (직접 업로드 = 픽셀 회전 저장 / 외부 URL = 각도 메타데이터 저장 후 표시 시 CSS 회전)
- "Search Google Images" 링크: 제목 클립보드 복사 + 구글 이미지 새 탭

C. 스마트 자동완성 (핵심 차별점)

- 저자/삽화가/출판사: 기존 데이터에서 추출한 datalist
- 빈 칸일 땐 목록 안 뜸 — 타이핑 시작하면 포함 매칭으로 최대 8개
- 시리즈 상속: 제목에서 뒤 숫자·레벨 표기 제거해 시리즈 키 생성
  ("Write Right 2-Beginner" → "write right")
  → 같은 시리즈 기존 항목의 출판사/분류/가격 등을 빈 칸에만 자동 채움
- 같은 저자 상속: 저자 blur 시 그 저자의 기존 Category/Genre/삽화가 상속
- 원칙: 자동은 빈 칸만 채운다. 사용자가 건드린 칸(dataset.touched)은 절대 덮어쓰지 않는다

D. 파생 필드

- AR Level 입력 → 색상 레벨 밴드(L1~L5) 자동 계산·표시 (읽기전용)
- 대문자 출판사명 자동 교정 (HARPERCOLLINS → HarperCollins)
- ISBN은 숫자·X만 남기고 자동 정리
4. 이식용 프롬프트 (다른 앱 개발 AI에게 그대로 전달)
내 라이브러리 앱의 "항목 추가" 모달을 아래 스펙으로 재설계해줘.

[레이아웃]
1. 최상단: 전체 폭 검색바 + Search 버튼. 이게 주 입력 수단.
   Enter로 검색 실행. 모달 열 때마다 검색창/결과/상태문구 완전 초기화.
2. 본문 2단: 왼쪽 160px 고정 표지 열, 오른쪽 정보 그리드(2열).
3. 정보 그리드 순서: Title*|Publisher / Author|Illustrator /
   Category|Genre / ISBN|Level(읽기전용). 관련 필드끼리 짝지을 것.
4. 등록 시점에 불필요한 필드(진행률, 평점, 상태 등)는 모달에서 제거
   — 편집 화면으로 이동.
5. 하단: Delete(왼쪽, 빨강 테두리) / Cancel·Save(오른쪽, Save는 강조색).

[표지]
- 표지 박스 하나가 클릭 업로드+드래그앤드롭+Ctrl V 붙여넣기 전부 처리.
  별도 upload/clear 버튼 노출 금지.
- 업로드 이미지는 520px JPEG로 자동 압축.
- 박스 아래 "↻ 90°" 회전 버튼과 "Search Google Images" 텍스트 링크만.

[자동화 — 가장 중요]
- 검색 결과 클릭 시 제목/저자/출판사/ISBN/표지 자동 입력 후
  "자동 입력됨, 필요시 수정" 한 줄 안내.
- 저자/출판사 필드: 기존 데이터 기반 자동완성. 단 빈 칸에서는
  목록을 띄우지 말고, 타이핑 시작 후 포함 매칭 최대 8개.
- 시리즈 인식: 제목 끝의 숫자/레벨 단어(beginner, level, vol 등)를
  제거한 키가 같으면 동일 시리즈로 보고, 기존 항목의 출판사/분류를
  빈 칸에 자동 상속.
- 절대 규칙: 자동 채움은 빈 칸만. 사용자가 수정한 필드는
  touched 플래그로 추적해 다시 덮어쓰지 않는다.
