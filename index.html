Add a task for a specific date. It will show up on the calendar and, if it's today, on the Notebooks page study list. Tag it with a subject so "go to note" knows which notebook to open.

backup & restore

Everything is stored only in this browser (localStorage), including any images you add to notes. Download a backup file regularly — it's the only way to recover your notes if browser data gets cleared, and it also lets you move your notes to another browser or computer. Loading a backup replaces what is in this browser with the file's contents.

clear all data

Clearing removes all notes, tasks, cards, and images from this browser. Browser storage has a limit of a few megabytes total, so avoid pasting dozens of large images.

StudyDesk란?

StudyDesk는 코넬(Cornell) 노트 필기법을 기반으로 한 개인 공부 노트 앱입니다. 강의, 독서, 자습 등 여러 활동을 과목별 노트북으로 나누어 기록하고, 학습 일정과 노트를 연결해 "오늘 공부할 것"에서 클릭 한 번으로 필기를 이어갈 수 있도록 설계되었습니다.

  • 설치 없음 — 브라우저에서 바로 실행됩니다. 별도 프로그램 설치나 회원 가입이 필요 없습니다.
  • 데이터는 내 브라우저에만 — 모든 노트는 이 브라우저 안(localStorage)에만 저장됩니다. 외부 서버로 전송되지 않아 사생활이 보호됩니다.
  • 필기 흐름 자동화 — 새 페이지를 만들면 날짜가 자동 입력되고, 필기가 페이지를 넘치면 다음 페이지가 자동으로 생성되며, 일정의 go to note 버튼으로 해당 노트북의 마지막 페이지가 바로 열립니다.

페이지별 기능

Notebooks
메인 화면입니다. 노트북 목록·검색·필터, 코넬 노트 편집기, 오늘의 공부 목록이 모여 있습니다. (아래 상세 참고)
Library
공부한 자료(책·영화·인강·논문·음악 등)의 카탈로그입니다. 제목 검색으로 정보를 자동으로 채우고, 상태(want / in progress / done)와 진행률·별점을 관리하며, go to note로 해당 자료의 노트북과 연결할 수 있습니다. (아래 상세 참고)
Calendar
한 달 달력에 반복 일정과 단발 일정이 표시됩니다. 날짜의 +N more를 누르면 그날의 전체 일정과 go to note 버튼이 나옵니다.
Schedule manager
반복 일정(요일 선택)과 단발 일정(날짜 지정)을 등록·삭제합니다. 모든 일정에 과목(subject)과 활동 유형(type)을 붙여 노트북과 연결합니다. (아래 상세 참고)
Flashcards
과목별 암기 카드를 만들고 review mode로 복습합니다. 카드를 클릭하면 앞/뒤가 뒤집히고, Esc 키나 close로 닫습니다.
Backup
백업 파일 내려받기(download backup)·불러오기(load backup), 백업 알림 주기, 현재 저장 공간 사용량, 그리고 전체 데이터 삭제가 모여 있는 전용 페이지입니다. (아래 "데이터 보관" 참고)
Settings
글꼴 스타일(handwritten / clean sans-serif), 노트 글자 크기, 자동 채우기 키, 그리고 이 설명서가 있습니다.

코넬 노트 작성 자세히

노트북 하나는 "한 과목의 한 활동"을 담습니다. 예를 들어 economics 과목이라도 강의 노트(lecture)와 독서 노트(book)는 서로 다른 노트북입니다.

고정 정보 — 노트북을 만들 때 한 번 정합니다
SUBJECT(과목), TYPE(활동 유형: lecture / book / movie / project / self-study / other), TOPIC(노트북 이름)
페이지별 정보 — 공부한 날마다 바뀝니다
chapter / subtitle(그날 다룬 챕터), tags / keywords(키워드), 날짜(새 페이지 생성 시 오늘 날짜가 자동 입력)

본문은 코넬 노트의 3구역 구조입니다. 왼쪽 CUE에 복습용 질문·키워드를, 오른쪽 MAIN NOTES에 본 필기를, 아래 SUMMARY에 요약을 적습니다.

  • 서식 도구 — MAIN NOTES 위 도구줄에서 굵게·기울임·형광펜·글자색(검정/빨강/파랑)·들여쓰기·라벨·링크·이미지를 사용할 수 있습니다.
  • 마크다운 단축 입력 — **굵게**, *기울임*, ==형광펜==을 입력하면 즉시 서식으로 바뀝니다.
  • 이미지 — 이미지 버튼으로 파일을 선택하거나, 복사한 이미지를 Ctrl+V로 바로 붙여넣을 수 있습니다. 큰 이미지는 저장 공간 보호를 위해 자동으로 축소됩니다(긴 변 1280px).
  • 페이지 넘기기 — 노트 좌우의 ◀ ▶ 화살표로 이동합니다. 마지막 페이지에서 ▶를 누르면 새 페이지가 만들어집니다. 필기가 화면을 넘치면 자동으로 다음 페이지가 생성됩니다.
  • 페이지 바로 이동 — 하단의 페이지 번호(N / M)를 클릭하면 전체 페이지 목록(챕터·날짜·미리보기)이 열리고, 원하는 페이지로 바로 이동할 수 있습니다.
  • self-test (복습 모드) — 하단의 self-test 버튼을 누르면 MAIN NOTES가 흐려져 가려집니다. 왼쪽 CUE의 질문·키워드만 보고 내용을 스스로 떠올려 보세요 — 코넬 필기법의 핵심 복습 단계입니다. show notes를 누르면 다시 보입니다.
  • 저장 — 입력하는 즉시 자동 저장됩니다. save 버튼은 저장 상태를 확인하는 용도입니다.

일정과 노트 연결하기 (추천 워크플로우)

  1. Schedule manager에서 반복 일정을 등록합니다. 예: 제목 "economics 101 lecture", 과목 economics, 유형 lecture, 요일 월·수·금.
  2. 해당 요일이 되면 Notebooks 페이지의 today's study list에 그 일정이 자동으로 나타납니다.
  3. 공부를 시작할 때 일정 옆의 go to note 버튼을 누릅니다. 그 과목·유형의 노트북이 마지막 페이지(지난 필기)로 열립니다. 노트북이 없으면 자동으로 만들어집니다.
  4. 지난 내용을 훑어본 뒤 ▶ 화살표로 새 페이지를 만들고, chapter에 오늘 진도를 적고 필기를 시작합니다.
  5. 공부가 끝나면 목록의 체크박스를 눌러 완료 표시합니다.

Library 사용하기

공부에 쓰는 모든 자료를 한 곳에서 관리합니다. 노트북과는 별개의 목록이므로, 노트를 쓰지 않은 자료도 자유롭게 등록할 수 있습니다. 등록 흐름은 "검색 한 번, 나머지는 확인만" 입니다 — 맨 위 검색창에 제목을 넣고 결과를 클릭하면 아래 필드가 자동으로 채워집니다.

  • 자동 채우기 — 유형을 고르고 제목을 검색하면 저자·출판사·표지 등이 채워집니다. 책(Google Books)·음악(MusicBrainz)·논문(Crossref)은 바로 되고, 영화/TV는 무료 TMDB 키를 Settings → auto-fill에 넣으면 켜집니다(선택사항). 직접 입력한 칸은 자동 채우기가 절대 덮어쓰지 않습니다.
  • 표지 — 표지 박스 하나가 전부입니다: 클릭하면 파일 선택, 이미지를 끌어다 놓거나, 복사한 이미지를 모달 안에서 Ctrl+V 하면 바로 들어갑니다(자동 압축). 박스 아래 ↻ 90°로 회전, search google images로 표지를 찾을 수 있습니다.
  • Category와 Genre — Category는 자료의 형태(Novel, Documentary, Online Course...), Genre는 주제(Economics, History...)입니다. 같은 저자·시리즈("Write Right 2 - Beginner"와 "Write Right 3"도 같은 시리즈로 인식)의 자료를 추가하면 이전 분류·출판사를 빈 칸에 자동으로 이어받습니다.
  • 상태와 진행률 — 등록할 때는 핵심 정보만 입력하고, 상태(want / in progress / done)·진행률·별점·청구기호는 편집(연필 버튼)에서 관리합니다. 진행 중인 자료는 카드에 진행률 막대가 표시됩니다.
  • 레벨 — 영화는 연령등급(Rated PG), 강의·영상은 난이도(Beginner...), 논문은 연도를 넣으면 배지가 표시됩니다. 책과 음악에는 레벨 항목이 없습니다.
  • 노트북 연결 — 카드의 go to note를 누르면 과목을 골라 그 자료의 노트북을 만들거나 열 수 있습니다. 삭제는 편집 화면 왼쪽 아래의 Delete 버튼입니다.
  • 일괄 편집 — 카드의 체크박스로 여러 개를 선택하면 상단에 bulk edit 바가 나타나 Category/Genre/상태를 한 번에 바꿀 수 있습니다.

데이터 보관 — 꼭 읽어주세요

모든 데이터(노트·일정·카드·이미지)는 지금 사용 중인 브라우저 한 곳에만 저장됩니다. 다음 경우 데이터가 사라지거나 보이지 않으니 주의하세요.

  • 브라우저의 인터넷 사용 기록(쿠키·사이트 데이터) 삭제 시 모든 노트가 삭제되며 복구할 수 없습니다.
  • 다른 브라우저(예: Chrome ↔ Edge)나 다른 컴퓨터·폰에서 열면 빈 상태로 시작합니다. 기기 간 동기화 기능은 아직 없습니다(다음 단계). 옮길 때는 아래 백업 파일을 쓰세요.
  • 시크릿/비공개 창에서는 창을 닫는 순간 데이터가 사라집니다.
  • Backup → download backup으로 백업 파일(JSON)을 주기적으로 내려받아 두세요. 데이터가 사라졌을 때 load backup으로 복원할 수 있는 유일한 수단이며, 다른 브라우저나 컴퓨터로 노트를 옮길 때도 이 파일을 사용합니다.
  • 마지막 백업 후 일정 기간이 지나면 화면 상단에 백업 알림 배너가 나타납니다. 배너의 backup now를 누르면 바로 내려받아지고, 알림 주기는 Backup → remind me to back up에서 3·7·14·30일 또는 끄기(never)로 바꿀 수 있습니다.
  • 저장 공간은 브라우저당 수 MB로 제한됩니다. 큰 스크린샷을 수십 장 붙여넣으면 저장이 실패할 수 있습니다.

폰·태블릿에 앱으로 설치하기

StudyDesk는 설치형 웹앱(PWA)입니다. 앱스토어 없이 브라우저에서 바로 설치되며, 설치 후에는 홈 화면 아이콘으로 전체 화면으로 열리고 인터넷이 없어도 열립니다.

  1. 폰 브라우저에서 https://amber67-git.github.io/studydesk/ 를 엽니다.
  2. Android(Chrome): 오른쪽 위 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가.
  3. iPhone/iPad(Safari): 아래 공유 버튼(□↑) → 홈 화면에 추가. (iOS는 Safari에서만 설치됩니다.)
  4. PC(Chrome/Edge): 주소창 오른쪽의 설치 아이콘을 누르면 창 하나짜리 앱으로 열립니다.
  • 설치된 앱은 인터넷이 연결돼 있으면 열 때마다 최신 버전을 받아옵니다. 예전 화면이 보이면 앱을 완전히 닫았다가 다시 여세요.
  • Library 자동 채우기(책·영화 검색)는 인터넷이 있을 때만 동작합니다. 필기·일정·카드는 오프라인에서도 모두 됩니다.
  • 데이터는 여전히 기기마다 따로 저장됩니다. 폰과 PC가 서로 다른 노트를 갖게 되니, 옮길 때는 Backup 페이지의 백업 파일을 쓰세요. 기기 간 자동 동기화는 다음 단계에서 추가됩니다.

자주 묻는 질문

화면 표시

서식 버튼(굵게, 색상 등) 일부가 안 보여요.
창 폭이 좁으면 도구줄이 가로로 스크롤됩니다. 도구줄 위에서 마우스 휠(또는 트랙패드 가로 스와이프)로 옆으로 밀면 나머지 버튼이 나타납니다. 창을 넓혀도 해결됩니다.
아이콘이 있어야 할 자리가 빈 네모로 보여요.
구버전에서 외부 아이콘 글꼴이 차단될 때 생기던 문제입니다. 현재 버전은 아이콘이 앱 안에 내장되어 있어 인터넷이 끊겨도 항상 표시됩니다. 이 증상이 보인다면 예전 파일을 열고 계신 것이니 최신 파일로 교체하세요.

데이터

어제 쓴 노트가 전부 사라졌어요.
먼저 (1) 같은 브라우저가 맞는지, (2) 시크릿 창이 아닌지, (3) 최근 브라우저 데이터 정리를 했는지 확인하세요. 다른 브라우저에서 열면 데이터가 없는 것이 정상입니다. 백업 파일이 있다면 Backup → load backup으로 복원할 수 있습니다. 백업이 없는 상태에서 브라우저 데이터를 삭제한 경우에는 복구할 수 없습니다.
이미지를 붙여넣은 뒤 저장이 느리거나 실패해요.

"not saving — this browser is blocking storage" 라고 떠요.
시크릿(비공개) 창이거나 브라우저가 사이트 데이터를 차단한 상태입니다. 이 상태에서는 필기가 저장되지 않습니다. 일반 창에서 열어주세요. 이미 작업한 내용이 있다면 창을 닫기 전에 Backup → download backup으로 파일을 먼저 받아두세요.
백업 파일을 불러왔는데 "that backup could not be loaded" 라고 떠요.
