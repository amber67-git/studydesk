StudyDesk 사용 설명서

이 앱의 목적

열자마자, 공부한 내용을 바로 적는다. StudyDesk의 모든 화면과 기능은 이 한 문장을 기준으로 만들고 판단합니다. 새 기능이나 디자인 변경은 "첫 글자를 쓰기까지의 탭 수가 줄어드는가"로 가치를 재며, 그렇지 않은 변경(장식, 색상 테마 등)은 뒤로 미룹니다.

  • 첫 화면은 종이 — 앱을 열면 마지막에 쓰던 노트북의 그 페이지가 다시 열립니다(기기별로 기억). PC에서는 커서가 이미 MAIN NOTES에 있어 바로 타이핑하면 되고, 폰에서는 종이가 맨 위에 오고 노트북 목록·오늘 목록·통계는 그 아래에 있습니다(상단 notebooks 버튼으로 목록까지 내려갑니다). 백업·주소 안내 띠는 화면 아래에 붙어 종이를 밀어내지 않습니다.
  • 손이 덜 가게 — 입력 즉시 자동 저장, 새 페이지의 날짜 자동 입력, 글이 넘치면 자동으로 다음 페이지, 일정에서 go to note 한 번으로 해당 노트북.
  • 코넬 노트 그대로 — CUE(핵심 질문) | MAIN NOTES(본문) | SUMMARY(요약) 구조와 self-test(본문 가리고 회상) 복습 단계를 종이와 같은 형태로 둡니다.
  • 내 데이터는 내 것 — 기본은 이 브라우저에만 저장, 백업 파일은 열린 JSON, 기기 간 동기화는 선택이며 본인 계정 공간에만 저장됩니다.

StudyDesk란?

StudyDesk는 코넬(Cornell) 노트 필기법을 기반으로 한 개인 공부 노트 앱입니다. 강의, 독서, 자습 등 여러 활동을 과목별 노트북으로 나누어 기록하고, 학습 일정과 노트를 연결해 "오늘 공부할 것"에서 클릭 한 번으로 필기를 이어갈 수 있도록 설계되었습니다.

  • 설치 없음 — 브라우저에서 바로 실행됩니다. 별도 프로그램 설치나 회원 가입이 필요 없습니다.
  • 데이터는 기본적으로 내 브라우저에만 — 로그인하지 않으면 모든 노트는 이 브라우저 안(localStorage)에만 저장되고 어디로도 전송되지 않습니다. Settings → Account 탭(cloud sync)에서 Google 계정으로 로그인하면 본인만 접근할 수 있는 클라우드 공간(Firebase)에 복사되어 다른 기기와 동기화됩니다.
  • 필기 흐름 자동화 — 새 페이지를 만들면 날짜가 자동 입력되고, 필기가 페이지를 넘치면 다음 페이지가 자동으로 생성되며, 일정의 go to note 버튼으로 해당 노트북의 마지막 페이지가 바로 열립니다.

페이지별 기능

Notebooks
메인 화면입니다. 코넬 노트 편집기, 노트북 목록·검색·필터, 오늘의 공부 목록이 모여 있습니다. 열면 마지막에 쓰던 노트북의 그 페이지가 열립니다. (아래 상세 참고)
Library
공부한 자료(책·영화·인강·논문·음악 등)의 카탈로그입니다. 제목 검색으로 정보를 자동으로 채우고, 상태(want / in progress / done)와 진행률·별점을 관리하며, go to note로 해당 자료의 노트북과 연결할 수 있습니다. (아래 상세 참고)
Calendar
한 달 달력에 반복 일정과 단발 일정이 표시됩니다. 날짜의 +N more를 누르면 그날의 전체 일정과 go to note 버튼이 나옵니다.
Schedule manager
반복 일정(요일 선택)과 단발 일정(날짜 지정)을 등록·삭제합니다. 모든 일정에 과목(subject)과 활동 유형(type)을 붙여 노트북과 연결합니다. (아래 상세 참고)
Flashcards
과목별 암기 카드를 만들고 review mode로 복습합니다. 카드를 클릭하면 앞/뒤가 뒤집히고, Esc 키나 close로 닫습니다.
Settings
탭 여섯 개로 나뉘어 있습니다. Backup(백업 파일 내려받기 download backup·불러오기 load backup, 백업 알림 주기, 저장 공간 사용량. 맨 아래 빨간 테두리 안에 전체 데이터 삭제 clear all data) · Account(cloud sync, 기기 간 동기화) · Display(글꼴 스타일 handwritten / clean sans-serif, 노트 글자 크기) · Lists(과목, Library 카테고리·장르 목록 관리. 아래 "Lists 탭" 참고) · Integrations(자동 채우기 키) · Guide(이 설명서). 마지막에 본 탭을 기억합니다. (아래 "데이터 보관" 참고)

코넬 노트 작성 자세히

노트북 하나는 "한 과목의 한 활동"을 담습니다. 예를 들어 economics 과목이라도 강의 노트(lecture)와 독서 노트(book)는 서로 다른 노트북입니다.

고정 정보 — 노트북을 만들 때 한 번 정합니다
SUBJECT(과목), TYPE(활동 유형: lecture / book / movie / project / self-study / other), TOPIC(노트북 이름)
페이지별 정보 — 공부한 날마다 바뀝니다
chapter / subtitle(그날 다룬 챕터), tags / keywords(키워드), 날짜(새 페이지 생성 시 오늘 날짜가 자동 입력)

본문은 코넬 노트의 3구역 구조입니다. 왼쪽 CUE에 복습용 질문·키워드를, 오른쪽 MAIN NOTES에 본 필기를, 아래 SUMMARY에 요약을 적습니다.

  • 서식 도구 — MAIN NOTES 위 도구줄에서 굵게·기울임·형광펜·글자색(검정/빨강/파랑)·들여쓰기·라벨·링크·이미지를 사용할 수 있습니다.
  • 마크다운 단축 입력 — **굵게**, *기울임*, ==형광펜==을 입력하면 즉시 서식으로 바뀝니다.
  • 이미지 — 이미지 버튼으로 파일을 선택하거나, 복사한 이미지를 Ctrl+V로 바로 붙여넣을 수 있습니다. 큰 이미지는 저장 공간 보호를 위해 자동으로 축소됩니다(긴 변 1280px).
  • 페이지 넘기기 — 노트 좌우의 ◀ ▶ 화살표로 이동합니다. 화면이 좁을 때(폰, 분할 화면 등)는 화살표가 종이를 가리지 않도록 노트 맨 아래 페이지 번호(1 / 3) 양옆으로 옮겨집니다. 마지막 페이지에서 ▶를 누르면 새 페이지가 만들어집니다. 필기가 화면을 넘치면 자동으로 다음 페이지가 생성됩니다. PC에서 가득 채운 페이지를 폰처럼 좁은 화면에서 열면 한 화면에 다 안 들어갈 수 있는데, 이때는 MAIN NOTES 안을 위아래로 스크롤하면 나머지 줄이 보입니다(내용은 잘리지 않습니다).
  • 페이지 바로 이동 — 하단의 페이지 번호(N / M)를 클릭하면 전체 페이지 목록(챕터·날짜·미리보기)이 열리고, 원하는 페이지로 바로 이동할 수 있습니다.
  • self-test (복습 모드) — 하단의 self-test 버튼(폭이 좁은 폰에서는 눈 아이콘만 보임)을 누르면 MAIN NOTES가 흐려져 가려집니다. 왼쪽 CUE의 질문·키워드만 보고 내용을 스스로 떠올려 보세요 — 코넬 필기법의 핵심 복습 단계입니다. show notes를 누르면 다시 보입니다.
  • 저장 — 입력하는 즉시 자동 저장됩니다. save 버튼은 저장 상태를 확인하는 용도입니다.

일정과 노트 연결하기 (추천 워크플로우)

  1. Schedule manager에서 반복 일정을 등록합니다. 예: 제목 "economics 101 lecture", 과목 economics, 유형 lecture, 요일 월·수·금.
  2. 해당 요일이 되면 Notebooks 페이지의 today's study list에 그 일정이 자동으로 나타납니다.
  3. 공부를 시작할 때 일정 옆의 go to note 버튼을 누릅니다. 그 과목·유형의 노트북이 마지막 페이지(지난 필기)로 열립니다. 노트북이 없으면 자동으로 만들어집니다.
  4. 지난 내용을 훑어본 뒤 ▶ 화살표로 새 페이지를 만들고, chapter에 오늘 진도를 적고 필기를 시작합니다.
  5. 공부가 끝나면 목록의 체크박스를 눌러 완료 표시합니다.

Library 사용하기

공부에 쓰는 모든 자료를 한 곳에서 관리합니다. 노트북과는 별개의 목록이므로, 노트를 쓰지 않은 자료도 자유롭게 등록할 수 있습니다. 등록 흐름은 "검색 한 번, 나머지는 확인만" 입니다 — 맨 위 검색창에 제목을 넣고 결과를 클릭하면 아래 필드가 자동으로 채워집니다.

  • 자동 채우기 — 유형을 고르고 제목을 검색하면 저자·출판사·표지 등이 채워집니다. 책(Google Books)·음악(MusicBrainz)·논문(Crossref)은 바로 되고, 영화/TV는 무료 TMDB 키를 Settings → Integrations → auto-fill에 넣으면 켜집니다(선택사항). 직접 입력한 칸은 자동 채우기가 절대 덮어쓰지 않습니다.
  • 표지 — 표지 박스 하나가 전부입니다: 클릭하면 파일 선택, 이미지를 끌어다 놓거나, 복사한 이미지를 모달 안에서 Ctrl+V 하면 바로 들어갑니다(자동 압축). 박스 아래 ↻ 90°로 회전, search google images로 표지를 찾을 수 있습니다.
  • Category와 Genre — Category는 자료의 형태(Novel, Documentary, Online Course...), Genre는 주제(Economics, History...)입니다. 같은 저자·시리즈("Write Right 2 - Beginner"와 "Write Right 3"도 같은 시리즈로 인식)의 자료를 추가하면 이전 분류·출판사를 빈 칸에 자동으로 이어받습니다. 드롭다운에 없는 값은 맨 아래 + Custom…으로 그 자리에서 추가하고, 목록 정리(추가·이름 변경·합치기)는 Settings → Lists에서 합니다.
  • 상태와 진행률 — 등록할 때는 핵심 정보만 입력하고, 상태(want / in progress / done)·진행률·별점·청구기호는 편집(연필 버튼)에서 관리합니다. 진행 중인 자료는 카드에 진행률 막대가 표시됩니다.
  • 레벨 — 영화는 연령등급(Rated PG), 강의·영상은 난이도(Beginner...), 논문은 연도를 넣으면 배지가 표시됩니다. 책과 음악에는 레벨 항목이 없습니다.
  • 노트북 연결 — 카드의 go to note를 누르면 과목을 골라 그 자료의 노트북을 만들거나 열 수 있습니다. 삭제는 편집 화면 왼쪽 아래의 Delete 버튼입니다.
  • 일괄 편집 — 카드의 체크박스로 여러 개를 선택하면 상단에 bulk edit 바가 나타나 Category/Genre/상태를 한 번에 바꿀 수 있습니다.

Lists 탭 — 과목·카테고리·장르 관리

Settings → Lists에서 앱 곳곳의 선택 목록을 한곳에서 손봅니다.

  • subjects — 과목을 추가·이름 변경·삭제합니다. 각 줄에 그 과목을 쓰는 노트북·일정·카드 수가 보입니다. 사용 중인 과목을 지우면 먼저 "어느 과목으로 옮길지"를 묻고, 노트북·일정·카드를 모두 그쪽으로 옮긴 뒤 삭제합니다(두 과목을 합칠 때도 이 방법). 과목은 최소 하나는 남아야 해서 마지막 하나는 지울 수 없습니다. 같은 이름(대소문자 무시)은 두 번 만들 수 없습니다.
  • library categories / genres — Library 자료에 쓰인 값과 직접 추가한 값(CUSTOM 표시)이 사용 수와 함께 나옵니다. 기본 제공 값(Novel, History 등 약 60개)은 목록에 나오지 않고 드롭다운에만 있습니다. + category / + genre로 추가하면 자료에 쓰기 전에도 Library 입력창의 드롭다운에 나타납니다. 이름 변경은 그 값을 쓰는 모든 자료에 한 번에 적용되므로 철자가 다른 두 값을 합칠 때 쓰면 됩니다("Sci-fi" → "Science Fiction"). 자료가 쓰고 있는 값은 삭제 버튼이 없고(이름 변경으로 합치세요), 안 쓰는 custom 값만 지울 수 있습니다.
  • 이 변경은 모두 일반 데이터라 백업 파일에 들어가고, cloud sync가 켜져 있으면 다른 기기에도 반영됩니다.

데이터 보관 — 꼭 읽어주세요

모든 데이터(노트·일정·카드·이미지)는 지금 사용 중인 브라우저 한 곳에만 저장됩니다. 다음 경우 데이터가 사라지거나 보이지 않으니 주의하세요.

  • 브라우저의 인터넷 사용 기록(쿠키·사이트 데이터) 삭제 시 모든 노트가 삭제되며 복구할 수 없습니다.
  • 로그인하지 않은 상태에서는 다른 브라우저(예: Chrome ↔ Edge)나 다른 컴퓨터·폰에서 열면 빈 상태로 시작합니다. 여러 기기에서 같은 노트를 보려면 아래 "기기 간 동기화"를 켜세요. 일회성으로 옮길 때는 백업 파일도 됩니다.
  • 시크릿/비공개 창에서는 창을 닫는 순간 데이터가 사라집니다.
  • Settings → Backup → download backup으로 백업 파일(JSON)을 주기적으로 내려받아 두세요. 데이터가 사라졌을 때 load backup으로 복원할 수 있는 유일한 수단이며, 다른 브라우저나 컴퓨터로 노트를 옮길 때도 이 파일을 사용합니다.
  • 마지막 백업 후 일정 기간이 지나면 화면 상단에 백업 알림 배너가 나타납니다. 배너의 backup now를 누르면 바로 내려받아지고, 알림 주기는 Settings → Backup → remind me to back up에서 3·7·14·30일 또는 끄기(never)로 바꿀 수 있습니다. 처음 열어서 샘플 노트만 있을 때는 알림이 뜨지 않습니다(내 노트가 아니라서).
  • 저장 공간은 브라우저당 수 MB로 제한됩니다. 큰 스크린샷을 수십 장 붙여넣으면 저장이 실패할 수 있습니다.

StudyDesk 주소가 https://amber-studydesk.netlify.app/ 로 바뀌었습니다. 옛 주소 amber67-git.github.io/studydesk 는 ClassDesk 등 소유자의 다른 앱과 같은 사이트 주소를 썼는데, 현재 안드로이드 Chrome은 한 사이트 주소에 앱을 하나만 설치합니다(Chrome 쪽 버그로 보고돼 있습니다). 그래서 StudyDesk와 ClassDesk를 둘 다 앱으로 설치할 수 없었습니다(한쪽을 깔면 다른 쪽이 "already installed"). 같은 사이트 주소의 앱들은 브라우저 저장공간도 같이 써서, 한쪽에서 사이트 데이터를 지우면 다른 앱 데이터까지 지워지는 위험도 있었습니다.

브라우저 저장소는 주소마다 따로라서 노트는 자동으로 넘어가지 않습니다. 기기마다 한 번씩:

  1. 노트를 쓰던 곳에서 백업을 받습니다. 브라우저 탭에서 썼다면 옛 주소(https://amber67-git.github.io/studydesk/)를, 옛 주소로 설치한 앱에서 썼다면 그 앱을 열고 위쪽 안내 띠의 download backup(또는 Settings → Backup → download backup)을 누릅니다. iPhone·iPad는 홈 화면 앱과 Safari가 저장소를 따로 쓰므로, 앱에서 썼다면 반드시 앱에서 받으세요(Safari에서 받으면 다른 노트가 담깁니다).
  2. 새 주소(https://amber-studydesk.netlify.app/)를 열고 Settings → Backup → load backup으로 그 파일을 불러옵니다. 처음 열면 샘플 노트가 보이는데, 불러오면 바뀝니다.
  3. 새 주소에서 앱을 설치하고(아래 "폰·태블릿에 앱으로 설치하기"), 새 앱에 노트가 다 있는지 확인합니다. iPhone·iPad는 새 홈 화면 앱도 저장소가 따로라서, 설치한 앱 안에서 한 번 더 load backup을 해야 할 수 있습니다.
  4. 확인한 다음에만 옛 주소로 설치한 StudyDesk 앱을 삭제합니다(폰 설정 → 애플리케이션, iPhone은 홈 화면 아이콘 길게 눌러 삭제). Android에서는 사이트 데이터·저장공간 삭제는 누르지 마세요. 같은 사이트 주소의 ClassDesk 데이터까지 지워집니다.

옛 주소도 당분간 그대로 열립니다. 다만 Chrome이 설치를 권하지 않게 해 두었고, 옛 주소로는 앱을 설치하지 마세요(홈 화면에 직접 추가하는 것도 포함). ClassDesk와 다시 부딪히고 노트가 옛 주소에 쌓입니다. cloud sync(기기 간 동기화)는 아직 설정 전이라 지금은 백업 파일로만 옮길 수 있습니다. 나중에 cloud sync가 켜지면 그때부터는 새 주소에서 로그인만 해도 노트가 내려옵니다.

폰·태블릿에 앱으로 설치하기

StudyDesk는 설치형 웹앱(PWA)입니다. 앱스토어 없이 브라우저에서 바로 설치되며, 설치 후에는 홈 화면 아이콘으로 전체 화면으로 열리고 인터넷이 없어도 열립니다.

  1. 폰 브라우저에서 https://amber-studydesk.netlify.app/ 를 엽니다. (2026년 11월 4일에 주소가 바뀌었습니다. 위 "주소 이사" 참고)
  2. Android(Chrome): 오른쪽 위 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가.
  3. iPhone/iPad(Safari): 아래 공유 버튼(□↑) → 홈 화면에 추가. (iOS는 Safari에서만 설치됩니다.) 주의: iPhone에서는 홈 화면 앱과 Safari가 저장 공간을 따로 씁니다. Safari에서 이미 쓰던 노트가 있다면 설치 전에 Safari에서 Settings → Backup → download backup으로 파일을 받아 두고, 설치한 앱을 연 뒤 Settings → Backup → load backup으로 불러오세요. 자동으로 넘어오지 않습니다.
  4. PC(Chrome/Edge): 주소창 오른쪽의 설치 아이콘을 누르면 창 하나짜리 앱으로 열립니다.
  • 설치 직후에는 인터넷이 연결된 상태에서 앱을 한 번 열어주세요. 그때 오프라인용 파일이 저장되고, 그 다음부터 인터넷 없이도 열립니다. 설치만 하고 바로 비행기 모드로 열면 빈 화면이 나올 수 있습니다.
  • 설치된 앱은 인터넷이 연결돼 있으면 열 때마다 최신 버전을 받아옵니다. 예전 화면이 보이면 앱을 완전히 닫았다가 다시 여세요.
  • 옛 주소(amber67-git.github.io/studydesk)로 설치한 StudyDesk 앱이 있으면 위 "주소 이사" 순서대로 노트를 옮긴 뒤 지우세요.
  • Library 자동 채우기(책·영화 검색)는 인터넷이 있을 때만 동작합니다. 필기·일정·카드는 오프라인에서도 모두 됩니다.
  • 폰과 PC에서 같은 노트를 보려면 Settings → Account → cloud sync에서 같은 Google 계정으로 로그인하세요(아래 "기기 간 동기화" 참고). 로그인하지 않은 기기는 자기 브라우저에만 저장합니다.

기기 간 동기화 (cloud sync)

폰·태블릿·PC에서 같은 노트를 보려면 각 기기에서 Settings → Account → cloud sync → sign in with Google을 누르고 같은 Google 계정으로 로그인하세요. 그 뒤로는 한 기기에서 고친 내용이 몇 초 안에 다른 기기에 나타납니다.

  • 충돌 규칙: 같은 것을 두 기기에서 동시에 고치면 마지막 수정이 이깁니다. 서로 다른 노트북·페이지를 고친 경우에는 둘 다 반영됩니다.
  • 오프라인: 인터넷이 없어도 평소처럼 쓸 수 있고, 변경은 기기에 쌓였다가 연결되면 자동으로 올라갑니다. 사이드바 맨 아래 상태 표시가 synced면 최신, offline · will sync면 대기 중입니다.
  • 처음 로그인할 때: 노트가 하나도 없던 새 기기는 클라우드의 노트를 그대로 받습니다(샘플 노트는 버립니다). 이미 노트가 있던 기기는 클라우드와 합쳐지고, 양쪽에 같은 노트가 있으면 더 최근에 고친 쪽이 남습니다.
  • 용량 제한: 한 페이지에 큰 이미지가 여러 장 들어가 약 900KB를 넘으면 그 페이지만 동기화되지 않고 이 기기에만 남습니다. Settings 페이지의 cloud sync 칸에 빨간 글씨로 어떤 페이지인지 표시되니 이미지를 하나 줄이면 됩니다.
  • 다른 계정으로 로그인하면: 이 브라우저의 노트가 전에 다른 Google 계정과 동기화된 것이면 "다른 계정의 노트가 있다"고 묻습니다. 확인하면 로컬 사본을 버리고 새 계정의 노트를 내려받고, 취소하면 로그아웃된 채 로컬 노트가 그대로 남습니다. 두 계정의 노트가 섞여 올라가는 일을 막기 위한 장치입니다.
  • 로그아웃해도 이 기기의 노트는 지워지지 않습니다. clear all data는 로그인 중이면 이 기기의 사본만 지우고 새로고침 뒤 클라우드에서 다시 받아옵니다. 어디서나 지우려면 앱 안에서 노트북을 삭제하세요(삭제도 동기화됩니다).
